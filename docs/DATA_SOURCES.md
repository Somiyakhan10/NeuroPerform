# Data Sources

**NHANES 2011–2012 and 2013–2014**, CDC National Center for Health Statistics. Public domain. https://wwwn.cdc.gov/nchs/nhanes/

URL pattern: `https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/{2011|2013}/DataFiles/{FILE}_{G|H}.xpt`

| File | Variables |
|---|---|
| DEMO | age, sex, education |
| CFQ | DSST, animal fluency, CERAD recall |
| MGX | grip strength, 3 trials per hand |
| PAQ | recreational activity |
| DPQ | PHQ-9 |
| SLQ | sleep hours, trouble sleeping |
| BMX | BMI |

Sample: 19,931 records → 2,673 participants aged 60+ with DSST and all six grip trials.

Citation: Centers for Disease Control and Prevention, National Center for Health Statistics. *National Health and
Nutrition Examination Survey Data*, 2011–2014. Hyattsville, MD: U.S. Department of Health and Human Services.
